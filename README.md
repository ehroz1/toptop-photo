# PhotoSeek — универсальный поиск фото

Один поиск сразу по **Pixabay**, **Pexels**, **Unsplash**, **Wikimedia Commons**,
**Openverse** и (опционально) **Flickr** + быстрые кнопки для **Яндекс.Картинок**,
**Google Картинок** и **Pinterest**. Работает как обычная веб-страница — без
установки чего-либо, без сервера и без сборки.

## Как запустить

Проще всего — просто открыть `index.html` двойным кликом в любом браузере
(Chrome, Edge, Firefox, Safari). Всё уже настроено и должно сразу заработать.

Если браузер вдруг заблокирует запросы к API при открытии файла напрямую
(редко, но бывает в некоторых настройках Chrome), запустите локальный сервер
из папки проекта:

```bash
# любой из вариантов
npx serve .
# или
python3 -m http.server 8080
```

и откройте адрес, который покажет команда (например `http://localhost:8080`).

## Как выложить онлайн (GitHub Pages)

1. Зайдите в репозиторий на GitHub → **Settings → Pages**.
2. В разделе "Build and deployment" выберите источник **Deploy from a branch**,
   ветку — ту, в которую запушен код, папку — `/ (root)`.
3. Через минуту-две GitHub покажет ссылку вида
   `https://<ваш-логин>.github.io/toptop-photo/` — это и есть ваш личный
   поисковик, доступный с телефона и любого компьютера.

## Что умеет

- **Поиск сразу в нескольких источниках** — Pixabay, Pexels, Unsplash,
  Wikimedia Commons, Openverse и Flickr. Результаты перемешиваются в одну
  ленту, каждую карточку можно скачать одним кликом.
- **Отключение источников** — нажмите на чип источника, чтобы временно
  исключить его из поиска. Источники без настроенного ключа (сейчас —
  Flickr) просто не показываются в списке чипов.
- **Яндекс.Картинки / Google Картинки / Pinterest** — кнопки открывают эти
  сервисы в новой вкладке с уже введённым запросом (см. пояснение ниже, почему
  не "в общей ленте").
- **Фильтры** — качество (Full HD+), ориентация (гориз./верт./квадрат),
  сортировка (популярное/новое).
- **Просмотр фото** — клик по карточке открывает полноэкранный просмотр с
  тегами, описанием, автором, ссылкой на источник, копированием ссылки и
  скачиванием оригинала. Листать можно стрелками ← → на клавиатуре.
- **Светлая/тёмная тема** — кнопка в правом верхнем углу, запоминается.
- **Показать ещё** — подгрузка следующей страницы результатов.

## Почему Яндекс, Google и Pinterest — это кнопки, а не общая лента

У Pixabay/Pexels/Unsplash есть бесплатные публичные API — по ним можно
получать фото напрямую и показывать их в общей сетке. У Яндекс.Картинок и
Google Картинок бесплатного публичного API для поиска изображений нет:

- **Google** предлагает Custom Search JSON API, но он платный после 100
  запросов в день и требует создания отдельного "Search Engine" (нужен API key
  + Search Engine ID).
- **Яндекс** предлагает похожий платный API с похожими ограничениями.
- **Pinterest** вообще не даёт стороннему приложению искать по всему
  Pinterest: его официальный API умеет искать только пины в вашем
  собственном аккаунте (после входа и авторизации через OAuth). Открытого
  поиска "по всему Pinterest" для разработчиков нет — только платные сервисы
  на основе скрейпинга (обход условий использования Pinterest), их
  сознательно не подключал.

Поэтому сейчас кнопки просто открывают нужный сервис в новой вкладке с вашим
запросом — быстро и без плясок с регистрацией. Если позже заведёте платный
ключ Google Custom Search или Яндекса — пришлите его, и я добавлю их
результаты прямо в общую сетку.

(Раньше в качестве замены рассматривался **Bing Image Search API**, но
Microsoft полностью закрыла все Bing Search API 11 августа 2025 года —
старые ключи возвращают ошибку, новые выдать нельзя. Поэтому такого варианта
больше нет.)

## Про Flickr

Раньше Flickr выдавал бесплатный "Non-Commercial" API-ключ любому желающему.
Сейчас, чтобы вообще подать заявку на ключ, нужна платная подписка
**Flickr Pro** — бесплатного пути больше нет. Поэтому чип "Flickr" в
интерфейсе сейчас скрыт (код-то есть, включать нечем).

Если когда-нибудь оформите Flickr Pro и получите ключ — пришлите его, впишу
в [`js/config.js`](js/config.js) поле `FLICKR_API_KEY`, и чип появится сам,
без других изменений.

## API-ключи

Ключи Pixabay, Pexels и Unsplash лежат в файле [`js/config.js`](js/config.js).
Wikimedia Commons и Openverse ключей не требуют вовсе — они уже работают "из
коробки". Репозиторий публичный, так что все указанные там ключи видны всем,
кто откроет код — это осознанный выбор ради простоты (сделано по вашей
просьбе). Практические следствия:

- Если ключ когда-нибудь начнёт барахлить (например, кто-то другой начнёт им
  пользоваться и упрётся в лимит), просто зайдите в личный кабинет
  соответствующего сервиса, перевыпустите ключ и замените его в `js/config.js`.
- У Unsplash демо-ключи имеют лимит **50 запросов в час** — при активном
  использовании он может закончиться быстрее, чем у Pixabay/Pexels. Это не
  баг: просто подождите час или запросите повышенный лимит на
  unsplash.com/oauth/applications.
- У Openverse без регистрации тоже есть лимит на анонимные запросы (около
  100 в день с одного IP). Для личного использования обычно достаточно; если
  начнёт не хватать — на api.openverse.org можно бесплатно зарегистрировать
  приложение и получить более высокий лимит.
- Если решите не публиковать ключи в коде — переименуйте
  `js/config.example.js` в `js/config.js`, впишите туда свои ключи и добавьте
  `js/config.js` в `.gitignore`.

## Структура проекта

```
index.html          — разметка страницы
css/styles.css       — все стили, светлая/тёмная тема, иконки (встроены как SVG)
js/config.js         — API-ключи
js/providers.js      — обращения к Pixabay/Pexels/Unsplash API
js/app.js            — вся логика: поиск, фильтры, сетка, просмотр, скачивание
```

Никаких фреймворков и сборщиков — чистые HTML/CSS/JS, поэтому редактировать
и запускать можно без установки Node.js или чего-либо ещё.
